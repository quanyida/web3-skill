# 代币价值捕获路径（Value Capture）

**用途**：Step 5.5 祛魅检验的 Q5 必读。

**要回答的问题**：**协议赚钱 ≠ 代币赚钱。钱到底进没进代币持有人的口袋？**

绝大多数「代币研究」的失败不是看错数据，而是混淆了三个层次：

```
业务层：有真实收入吗？        → TVL / 费用 / 收入数据能回答
代币层：收入流向持币者吗？    → 本文要解决的问题
```

ENA 是标准反例：USDe + USDtb 锁着 $50 亿真实资金，四条收入流都在跑 —— 但官方文档写明储备基金分配 **0%**、100% 收入用于激励、Fee Switch 未激活。**协议很成功，代币零捕获。**

---

## 六条路径对照表

| 路径 | 说明 | 实际强度 | 常见问题 |
|---|---|---|---|
| **回购 / 销毁** | 用收入或储备金在市场上买回代币并销毁 | 中等偏弱 | 收入不稳定时很难持续；容易变成「画饼」 |
| **费用分享 / 分红** | 把协议真实收入按比例分给持币者 | **较强** | 需要真实、可持续的收入 |
| **强制使用（Utility）** | 必须持有或消耗代币才能使用核心功能 | **较强** | 很多项目做成了可选的「折扣券」 |
| **质押 / 锁仓** | 锁仓获得收益、权限或治理权重 | 中等 | 如果收益来自增发，本质是稀释 |
| **治理权** | 对参数、金库、路线有实质投票权 | 弱到中等 | 多数治理流于形式 |
| **纯叙事 / 投机** | 靠预期、社区、流动性炒作 | 短期强、长期弱 | 没有基本面支撑时容易归零 |

---

## 怎么验证（每条路径的「真 vs 画饼」判据）

光看官网宣称不算数。每条路径都要找**可验证证据**：

### 回购 / 销毁

| ✅ 真 | ❌ 画饼 |
|---|---|
| 链上可查到定期回购交易（地址 → DEX/OTC） | 只在官网写「将用收入回购」 |
| 销毁地址余额持续增长 | 销毁「计划」发布超过 6 个月但无链上动作 |
| 回购金额与披露收入量级匹配 | 回购金额远大于收入 —— 钱从哪来？增发？ |

**验证动作**：查销毁地址（`0x…dead`）余额时序；查官方回购地址的链上转账记录。

### 费用分享 / 分红

| ✅ 真 | ❌ 画饼 |
|---|---|
| 有明确的分配比例（如「收入的 50% 分给质押者」） | 只说「价值会流向社区」 |
| 可在链上/合约里看到实际分配流水 | 分配比例「待治理决定」 |
| 分配与真实收入挂钩，有波动 | 收益率恒定 —— 说明靠增发补贴，不是分成 |

**验证动作**：找一个完整周期的实际发放记录，对比同期协议收入。

### 强制使用（Utility）

| ✅ 真 | ❌ 画饼 |
|---|---|
| 不持有代币**无法**使用核心功能 | 「持有可享 8 折」—— 用不用都能用 |
| 消耗即销毁 / 锁定（真通缩） | 只是「折扣券」，且多数用户不买 |
| 需求量与产品使用量线性相关 | 代币需求靠人为制造的稀缺 |

**验证动作**：问「如果代币明天消失，产品还能不能用？」能用 → Utility 是假的。

### 质押 / 锁仓

| ✅ 真 | ❌ 画饼 |
|---|---|
| 收益来自**协议外部收入**（费用、利差） | 收益来自增发 —— 本质是稀释，零和 |
| 锁仓有实际机会成本（不能随时退出） | 无锁定期、可随时赎回 |
| 质押率稳定，非激励驱动 | 激励一停质押量暴跌 → 说明只为收益率 |

**验证动作**：算「质押年化 ÷ 通胀率」。若年化 < 通胀，质押者实际在亏。

### 治理权

| ✅ 真 | ❌ 画饼 |
|---|---|
| 治理能实质改变金库/参数/费用开关 | 投票只是「意见征集」 |
| 投票参与度实打实（非提案方自投） | 提案通过率 100%、参与率 <5% |
| 持币量分散，不被单一实体控制 | 前 10 地址占 80%，治理=摆设 |

**验证动作**：查最近 3 个提案的参与率和结果分布。

### 纯叙事 / 投机

| 性质 | 说明 |
|---|---|
| 不是「坏」路径 | PEPE 就是这样 —— 且它**从不假装**自己有业务 |
| 但有明确使用边界 | 不可用于长期价值判断；只适合情绪/资金流监控 |
| 关键区别 | 「诚实叙事」（PEPE）vs「叙事包装成业务」（QNT/BEAM）—— 后者更危险 |

## 历史案例对照（本项目已研究的对象）

| 对象 | 协议层 | 代币层 | 价值捕获路径 | 判定 |
|---|---|---|---|---|
| **ENA** | 真（$49.4 亿 TVL，四条收入流） | **零捕获** | 宣称「Buy and burn」+「Fee Switch」未激活 | 储备基金 0%、100% 收入给激励 → **钱到不了** |
| **PEPE** | 无业务 | 无业务 | 纯叙事 | 诚实 —— 从不假装有捕获 |
| **BEAM** | 链近乎空转（日费用 $16） | 无数据 | 宣称「Buy and burn」 | 未公布历史销毁量 → **画饼待验证** |
| **QNT** | 业务存疑 | 无 | 治理权 | DeFiLlama 零收录，企业客户不透明 → **无公开证据** |
| **NEAR** | 真（费用 $3,125/天） | 部分 | 质押 + 治理 | gas 消耗 + 验证者质押 → **部分真实** |

## 硬规则

- **协议成功不等于代币成功**。分两行写，不许合并成一个结论。
- 任何一条路径若只有官方宣称、没有链上/合约/第三方可验证证据 → 判定为「画饼，待验证」，不计入强度。
- 「Fee Switch 未激活」「储备基金 0%」这类**官方文档写明的空档**是最强的负面证据 —— 因为它是项目方自己承认的。
- 不要用「未来会开」来加成分数。判断当下，不判断路线图。
