      六条价值捕获路径

      判定「钱有没有进持币者口袋」的依据

      • 费用分享 / 分红较强把协议真实收入按比例分给持币者；收益率恒定说明靠增发
      • 强制使用 Utility较强必须持有或消耗代币才能用核心功能；做成「可选折扣券」就是假的
      • 回购 / 销毁中等偏弱用收入买回并销毁；收入不稳定时难持续，容易变成画饼
      • 质押 / 锁仓中等锁仓换收益或权限；收益来自增发本质是稀释
      • 治理权弱到中等对参数与金库有实质投票权；多数治理流于形式
      • 纯叙事 / 投机短强长弱靠预期与流动性炒作；无基本面支撑时容易归零

      硬规则：协议成功与代币成功分两行写，不许合并。只有官方宣称、无链上证据的路径记「画饼，待验证」，不计强度。
